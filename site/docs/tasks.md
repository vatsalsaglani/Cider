# Tasks

Cider’s task view gives each day a short, editable list while keeping richer task context close by. Tasks can stand alone, or connect to notes and observed agent conversations so plans, evidence, and follow-up stay together.

![Cider Today task view](images/tasks.png)

![Cider TODO notch](images/notch-todo.png)

## Plan a day

Open **Today** from the sidebar. The header shows the selected date and counts for open and completed work. Use the previous-day, next-day, and return-to-today buttons to move around. The week strip provides a quick seven-day view.

Switch to **Calendar view** for a month grid with task counts. Selecting a date updates the agenda, and the month arrows browse independently. Completed tasks are grouped below open tasks in the list.

## Add and change tasks

The day composer adds a task to the selected date and stays ready for the next entry. **Quick task** adds a task for today from the sidebar. The notch’s TODO tab has its own date controls, shows up to three remaining tasks, and lets you add or complete work without opening the main window.

Click a task title or its action menu to edit the title and planned day. A planned day is where Cider expects you to work; it is separate from an optional due date. Moving a task does not complete it or change an external issue. Check the circle to complete a task, then use the same control to reopen it.

## Use task details

Opening a task from Today shows a full task page. Edit its title and description, choose a status, add a due date, and write acceptance criteria with individual checkboxes. Cider shows **Save changes** only when the page has edits. If the saved task changes while you are editing, the page lets you compare the saved version and rebase your draft.

The task page also brings together:

- **Notes**, where you can attach an existing Markdown note or create a linked one. A link can be a plan, context, or evidence reference.
- **Chats**, where you can attach an observed Codex, Claude Code, or Cursor conversation as a contributor. Attaching a chat records future observed turns; it does not resume, fork, or message that chat.
- **Activity**, a saved timeline of reported responses, questions, and your own notes.

## Treat activity as evidence

A reported response or a stopped agent is useful evidence for review. It does not mark the task done, check an acceptance criterion, or prove that a person verified the result. From a response entry, **Save checkpoint to a note** opens a preview of the exact Markdown append and destination. Cider writes only after you confirm that preview.

Use **Back** and **Forward** in the workspace to move between tasks, notes, and graph views. Cider keeps an unfinished task draft while you follow a linked note.

## Work from the notch

Hover the notch for a quick view of the mascot, active agent count, and remaining tasks. Expand it to open the TODO tab. Click **Add a task…** to start a capture session, press Return to submit, or use Escape to dismiss while keeping the draft available. The task field takes keyboard focus only after you explicitly click to capture.

Select **Open Cider** in the notch when you need task descriptions, linked work, or the full timeline.
